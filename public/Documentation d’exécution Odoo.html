write

#
core

Route

/json/2/res.users.apikeys.description/write

Description

Update all records in self with the provided values.

  • For numeric fields (~odoo.fields.Integer, ~odoo.fields.Float) the value should be of the corresponding type

  • For ~odoo.fields.Boolean, the value should be a python:bool

  • For ~odoo.fields.Selection, the value should match the selection values (generally python:str, sometimes python:int)

  • For ~odoo.fields.Many2one, the value should be the database identifier of the record to set

  • The expected value of a ~odoo.fields.One2many or ~odoo.fields.Many2many relational field is a list of ~odoo.fields.Command that manipulate the relation the implement. There are a total of 7 commands: ~odoo.fields.Command.create, ~odoo.fields.Command.update, ~odoo.fields.Command.delete, ~odoo.fields.Command.unlink, ~odoo.fields.Command.link, ~odoo.fields.Command.clear, and ~odoo.fields.Command.set.

  • For ~odoo.fields.Date and ~odoo.fields.Datetime, the value should be either a date(time), or a string.

    Warning

    If a string is provided for Date(time) fields, it must be UTC-only and formatted according to odoo.tools.misc.DEFAULT_SERVER_DATE_FORMAT and odoo.tools.misc.DEFAULT_SERVER_DATETIME_FORMAT

  • Other non-relational fields use a string for value
